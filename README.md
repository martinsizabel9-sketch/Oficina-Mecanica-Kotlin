# Oficina Mecânica - Kotlin

Trabalho Prático MASTER - Estudo de Caso 8: Oficina Mecânica.

## Objetivo

Desenvolver um sistema simples para controle de ordem de serviço de uma oficina mecânica, permitindo cadastrar veículo, peças e serviços, calcular o valor total e acompanhar o status do serviço.

## Conteúdos utilizados

- Programação Orientada a Objetos (POO)
- Variáveis `val` e `var`
- Tipos `String`, `Int`, `Double` e `Boolean`
- Estrutura condicional `if/else`
- Estrutura `when`
- Laços de repetição `for`
- Null Safety
- Listas

## Funcionalidades

- Cadastro de veículo
- Cadastro de peças
- Cadastro de serviços
- Peça adicional opcional
- Cálculo do subtotal
- Desconto de 5% para pagamento à vista
- Controle do status da ordem de serviço

## Status da Ordem de Serviço

1. Orçamento
2. Em Conserto
3. Fase de Testes
4. Finalizado
